Introduction

Welcome to the Foliona Theme documentation. This modern, responsive template is designed for developers and creatives who want to showcase their work with style.

Foliona is a clean, professional template built with Bootstrap 5, featuring a modern design, dark mode support, and smooth animations. It's perfect for portfolios, personal websites, and creative showcases.

File Structure

The template is organized into the following structure:

foliona/
├── css/
│   └── style.css
├── js/
│   └── main.js
├── img/
├── index.html
├── about.html
├── blog.html
├── blog-single.html
├── contact.html
└── documentation/
    └── index.html

Key Files:

  • style.css: Contains all custom styles and theme variables
  • main.js: JavaScript functionality including theme toggle
  • index.html: Homepage with hero section and featured content
  • about.html: About page with personal information
  • blog.html: Blog listing page
  • blog-single.html: Individual blog post page
  • contact.html: Contact form and information

Setup Instructions

Getting Started

  1. Download and extract the template files
  2. Open the project in your preferred code editor
  3. Start editing HTML files to customize content
  4. Modify CSS in style.css for styling changes

Editing HTML

All HTML files use Bootstrap 5 classes for layout and components. You can modify content within the appropriate sections:

<section class="section-name">
    <div class="container">
        <!-- Your content here -->
    </div>
</section>

Customization

Changing Colors

Colors are defined in CSS variables at the top of style.css:

:root {
    --primary-color: #007bff;
    --text-color: #212529;
    --body-bg: #ffffff;
    /* ... other variables ... */
}

Changing Fonts

The template uses Poppins from Google Fonts. To change fonts:

  1. Update the Google Fonts link in HTML files
  2. Modify the font-family in style.css

Adding Images

Place images in the img/ folder and update image paths in HTML files.

Theme Modes

The template includes a built-in dark mode toggle. The theme switch is located in the navigation bar.

How it Works

Dark mode is controlled by JavaScript in main.js. When toggled:

  • Adds data-theme="dark" to the body
  • Updates CSS variables for dark colors
  • Persists the user's preference

Customizing Dark Mode

Dark mode colors are defined in style.css under the [data-theme="dark"] selector.

Placeholder Images

The template uses simple black placeholders instead of image files for:

  • Hero section background
  • About section profile image

This approach:

  • Eliminates dependency on external image services
  • Improves loading performance
  • Ensures ThemeForest compatibility
  • Makes it easier for users to replace with their own images

To replace the placeholders with your own images:

  1. For hero background: Add your image to the img folder and update the background-color to background-image in the hero section
  2. For about section: Replace the placeholder-image div with an img tag pointing to your image
