## ✨ Description
Foliona is a clean and elegant personal portfolio template crafted for front-end developers, designers, and creative professionals. This repository hosts the live preview only. The full version with documentation, assets, and source files is available exclusively through the ThemeForest license.

## 💡 Key Features
- Modern and responsive layout
- Blog pages and single post templates
- Dark mode support
- SEO-optimized HTML structure
- Easy navigation and animations
