# Foliona - Personal Portfolio Template

## Introduction
Foliona is a modern, responsive personal portfolio template designed for front-end developers, designers, and creative professionals. It features a clean, minimalist design with smooth animations and a dark mode option, making it perfect for showcasing your work and sharing your thoughts through a blog.

## Features
- 🎨 **Modern Design**: Clean and professional layout with smooth animations
- 📱 **Fully Responsive**: Looks great on all devices (desktop, tablet, mobile)
- 🌓 **Dark Mode**: Built-in dark/light theme toggle
- 📝 **Blog Section**: Complete blog functionality with single post pages
- 🎯 **Portfolio Showcase**: Elegant way to display your projects
- ⚡ **Fast Loading**: Optimized for performance
- 🔍 **SEO Friendly**: Proper meta tags and semantic HTML
- 🎨 **Customizable**: Easy to modify colors, content, and layout
- 📱 **Mobile First**: Designed with mobile-first approach
- 🎭 **Animations**: Smooth scroll and fade-in animations

## Installation
1. Download or clone this repository
2. Open `index.html` in your web browser
3. That's it! No build process or dependencies required

## Folder Structure
```
foliona/
├── css/
│   └── style.css          # Main stylesheet
├── js/
│   └── main.js            # Custom JavaScript
├── img/                   # Placeholder images only – real images not included in the package
├── index.html             # Homepage
├── about.html             # About page
├── blog.html              # Blog listing page
├── blog-single.html       # Single blog post template
└── contact.html           # Contact page
```

## Customization
### Colors
- Edit the CSS variables in `css/style.css` to change the color scheme
- Main colors are defined in the `:root` selector
- Dark mode colors are defined in `[data-theme="dark"]`

### Images
- Replace placeholder images in the `img/` folder
- Update image paths in HTML files
- Recommended image sizes:
  - Hero images: 1200x800px
  - Portfolio thumbnails: 800x600px
  - Blog featured images: 1200x630px

### Content
- Edit HTML files to update text content
- Modify meta tags in the `<head>` section
- Update social media links in the footer

### Blog Posts
- Create new blog posts by duplicating `blog-single.html`
- Update the content, images, and meta information
- Add links to new posts in `blog.html`
